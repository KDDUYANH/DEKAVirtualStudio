🎯 WHAT THIS DOES

Problem: Streamers waste time checking quality, switching cameras, managing 
         recordings across multiple tools

Solution: DEKA LIVE = One dashboard with real-time metrics + one-click control

Features:
  ✅ Real-time stream quality monitoring (bitrate, FPS, jitter, packet loss)
  ✅ Multi-camera dashboard (free: 1 camera, pro: 4 cameras)
  ✅ vMix scene switching (one-click)
  ✅ Quality alerts (automatic)
  ✅ Stream recording control
  ✅ Dark mode UI (optimized for streamers)
  ✅ Freemium monetization ($9.99/month for Pro tier)

🏗️ ARCHITECTURE

  Frontend (React)     Backend (Node.js)     Database (PostgreSQL)
  ├─ Dashboard      ←→ ├─ Express         ←→ ├─ Users
  ├─ Real-time        ├─ WebSocket           ├─ Cameras
  ├─ Dark mode        ├─ Auth               ├─ Subscriptions
  └─ Responsive       ├─ vMix control       └─ Metrics
                      └─ MediaMTX adapter

  All deployed to GCP Cloud Run with:
  - Cloud Load Balancer (HTTPS + SSL)
  - Cloud SQL (managed database)
  - Cloud Storage (recordings)
